Electronics

The model runs on one microcontroller, one chain of addressable LEDs, a few real sensors, a small fan and a buzzer. We have two controller plans: an ESP32 bought locally, or the Adafruit Feather M4 from the TechRise kit list. Both run the same logic.

Log record

Once a second the controller writes one line to the SD card and sends the same line over USB so the dashboard can plot it live.

t_ms, temp_C, rh_pct, co2_ppm, p_hPa, lux, act_idx, occupied,
hr_bpm, stress_idx, state, action, action_ms, led_mA

Notes before wiring

  • 3.3 V data driving 5 V LEDs usually needs a level shifter; if the first pixels flicker, that is why.
  • Never run the full LED chain at white from USB. Use a separate 5 V supply rated for at least 3 A, a large capacitor across the rails, and a common ground.
  • The MQ-135 gives an "air contamination index", not real ppm. The board label says so.
  • Measure every board with calipers before cutting any mounting holes.
